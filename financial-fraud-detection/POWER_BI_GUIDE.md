# Power BI Integration Guide

## How Power BI fits into this project

The Streamlit dashboard (`dashboard/app.py`) is the **primary, live application
dashboard** — it reads directly from `database/fraud_detection.db` and reflects
real-time predictions as the simulator/API run. The supplied Power BI (`.pbix`)
files are best treated as an **analytics/reporting layer**: a polished,
shareable report for stakeholders (e.g. compliance, risk-management leadership)
who work in Excel/Power BI rather than a web app, refreshed periodically from
an export of the same SQLite tables (or the `processed_transactions.csv` file).

Note: `.pbix` files are Power BI's proprietary binary format. This environment
could unzip the outer container (`.pbix` is a zip) but the `DataModel` payload
inside is a compressed, proprietary format that isn't parseable without Power
BI Desktop or `pbi-tools`. The recommendations below are therefore built from
the **actual columns in `financial_fraud_detection_dataset.csv`** (the schema
used throughout this project), not from guessed column names.

## Recommended Power BI Pages

1. **Executive Dashboard** — total transactions, total fraud, fraud rate,
   fraudulent amount, trend over time (mirrors dashboard page 1)
2. **Transaction Overview** — transaction volume/amount by category, payment
   method, device
3. **Fraud Analysis** — fraud rate broken down by every categorical dimension
4. **Risk Analysis** — risk-level distribution (requires importing the
   `predictions` table, which is generated by this project, not present in
   the raw CSV)
5. **Geographic Analysis** — fraud rate and volume by `Location`
6. **Customer Analysis** — per-`Customer_ID` frequency, average spend, and
   fraud incidence
7. **Model Performance** — import `reports/model_comparison.csv` and
   `models/feature_importance.csv` as static tables
8. **Fraud Investigation** — a drill-through page filtered to a single
   `Transaction_ID`

## Data Sources to Import

- `data/raw/financial_fraud_detection_dataset.csv` (or the cleaned
  `data/processed/processed_transactions.csv`)
- `reports/model_comparison.csv`
- `models/feature_importance.csv`
- (Optional, for live risk data) export the SQLite `predictions` and `alerts`
  tables to CSV, or connect Power BI directly to `database/fraud_detection.db`
  via an ODBC SQLite driver.

## DAX Measures (using the actual column names)

```dax
Total Transactions = COUNTROWS(financial_fraud_detection_dataset)

Total Fraud Transactions =
CALCULATE(
    COUNTROWS(financial_fraud_detection_dataset),
    financial_fraud_detection_dataset[Fraudulent] = 1
)

Fraud Rate % =
DIVIDE([Total Fraud Transactions], [Total Transactions], 0) * 100

Total Transaction Amount =
SUM(financial_fraud_detection_dataset[Transaction_Amount])

Fraudulent Amount =
CALCULATE(
    SUM(financial_fraud_detection_dataset[Transaction_Amount]),
    financial_fraud_detection_dataset[Fraudulent] = 1
)

Average Transaction Amount =
AVERAGE(financial_fraud_detection_dataset[Transaction_Amount])

Average Customer Spend =
AVERAGE(financial_fraud_detection_dataset[Average_Spend])

International Fraud Rate % =
DIVIDE(
    CALCULATE(
        COUNTROWS(financial_fraud_detection_dataset),
        financial_fraud_detection_dataset[Fraudulent] = 1,
        financial_fraud_detection_dataset[Is_International] = 1
    ),
    CALCULATE(
        COUNTROWS(financial_fraud_detection_dataset),
        financial_fraud_detection_dataset[Is_International] = 1
    ),
    0
) * 100

Suspicious Keyword Fraud Rate % =
DIVIDE(
    CALCULATE(
        COUNTROWS(financial_fraud_detection_dataset),
        financial_fraud_detection_dataset[Fraudulent] = 1,
        financial_fraud_detection_dataset[Suspicious_Keyword] = "Yes"
    ),
    CALCULATE(
        COUNTROWS(financial_fraud_detection_dataset),
        financial_fraud_detection_dataset[Suspicious_Keyword] = "Yes"
    ),
    0
) * 100

New Account Fraud Rate % =
DIVIDE(
    CALCULATE(
        COUNTROWS(financial_fraud_detection_dataset),
        financial_fraud_detection_dataset[Fraudulent] = 1,
        financial_fraud_detection_dataset[Account_Age_Days] < 30
    ),
    CALCULATE(
        COUNTROWS(financial_fraud_detection_dataset),
        financial_fraud_detection_dataset[Account_Age_Days] < 30
    ),
    0
) * 100

Amount Deviation from Average =
financial_fraud_detection_dataset[Transaction_Amount]
    - financial_fraud_detection_dataset[Average_Spend]
```

These use only columns confirmed to exist in the primary dataset
(`Transaction_ID`, `Customer_ID`, `Transaction_Date`, `Transaction_Amount`,
`Merchant_Category`, `Payment_Method`, `Device_Type`, `Location`,
`Is_International`, `Previous_Transactions`, `Average_Spend`,
`Account_Age_Days`, `Suspicious_Keyword`, `Fraudulent`) — no invented columns.
